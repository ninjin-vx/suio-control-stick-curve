# SuiOvOi Control Stick Curve Tool

SuiOvOi Control 用のスティックカーブ計算ツールです。

左スティックと右スティックをタブで切り替え、それぞれの設定に合わせて P1〜P10 の値を自動計算できます。

## Demo

GitHub Pages:
https://ninjin-vx.github.io/suio-control-stick-curve/

## 左スティック

START から P10 までを一直線になるように自動計算します。

- START X = 0.0 固定
- アンチデッドゾーン = START Y
- P10 Y = 100.0 固定
- P10 X = 10.0〜100.0
- P1〜P9 は START → P10 の間を10等分して自動計算
- START を上下ドラッグしてアンチデッドゾーンを変更可能
- P10 を左右ドラッグして P10 X を変更可能
- 表示は小数1桁

### アンチデッドゾーンを追加した理由

左スティック側にアンチデッドゾーンの設定項目を追加したのは、Apex Legends などで **「移動スティックのデッドゾーン」を小さく設定したい場合に、中心付近の出力開始位置を調整しやすくするため**です。

![Apex Legends の移動スティックのデッドゾーン設定](assets/move-stick-deadzone.png)

START Y を上げることで、スティックを中心から少し倒したときの初期出力を持ち上げ、実質的に中心付近の無反応領域を小さくする方向へ調整できます。

これはゲーム側の「移動スティックのデッドゾーン」設定そのものを変更する機能ではなく、コントローラー側の出力カーブで中心付近の反応を補正するための項目です。

## 右スティック

P9 の Y 値を指定し、P1〜P9 を原点から P9 までの完全な直線上に自動配置します。

固定値:

- P9 X = 99.8
- P10 X = 99.9
- P10 Y = 100.0
- 表示は小数1桁

操作:

- P9 Y を数値入力で変更可能
- グラフ上の P9 を上下ドラッグして変更可能
- P1〜P9 をリアルタイムで再計算

### なぜ右スティックは P10 ではなく P9 までをリニアにするのか

P10 までをリニア区間にすると挙動が不自然になるため、右スティックは P9 までをリニア区間にしています。

![P10 までリニアにしたときの挙動](assets/p10-behavior.gif)

## 設定保存

設定値はブラウザの `localStorage` に自動保存されます。

保存される項目:

- 左スティックのアンチデッドゾーン
- 左スティックの P10 X
- 右スティックの P9 Y
- 最後に開いていたタブ

同じPC・同じブラウザでは、ページを閉じても前回の設定から再開できます。

ブラウザのサイトデータを削除した場合や、別のブラウザ・別のPCでは設定は引き継がれません。

## Usage

`index.html` 単体で動作する静的Webツールです。

リポジトリをダウンロードして `index.html` をブラウザで開くか、GitHub Pages からそのまま使用できます。
